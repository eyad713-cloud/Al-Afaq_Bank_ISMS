Welcome to the **Al-Afaq Digital Bank** Information Security Management System (ISMS) repository. This project demonstrates a comprehensive, ISO/IEC 27001:2022 aligned security framework tailored for a modern, digital-first banking environment.

> **Disclaimer:** Al-Afaq Digital Bank is a **fictional organization** created solely for academic, educational, and portfolio-demonstration purposes. No real customer data, credentials, or proprietary vendor templates are included in this repository. All documents have been built using Clean Room Design principles.

---

## 📌 Project Overview
The ISMS is designed to protect customer data, ensure the availability of digital banking services (like *Afaq Plus* and *Afaq Net*), and meet strict regulatory requirements (such as SAMA and SDAIA). 

This repository contains the complete lifecycle of the ISMS, from context and risk assessment to incident response and internal auditing.

---

## 📂 Repository Structure

The project files are logically organized into the following core ISMS domains:

### 1. Context, Scope & Objectives
*   **ISMS Context, Requirements, and Scope:** Defines the organizational boundaries and interested parties.
*   **ISMS Objectives:** Strategic security goals and measurable targets.
*   **Statement of Applicability (SoA):** ISO 27001 Annex A controls applicability and justification.

### 2. Policies & Procedures
*   **Information Security Policy:** The overarching security governance document.
*   **Acceptable Use Policy:** Rules for secure access and handling of bank assets.
*   **Information Security Incident Response Procedure:** Step-by-step guide for handling and reporting cyber incidents.

### 3. Risk Management
*   **Security Risk Assessment & Treatment Methodology:** The framework for identifying and evaluating risks.
*   **Information Security Risk Appetite Statement:** Management's threshold for acceptable risk.
*   **Asset-Based Risk Tool (Excel):** Dynamic registers for tracking assets, threats, vulnerabilities, and risk scores.
*   **Information Security Risk Assessment Report:** Executive summary of critical risks and mitigation strategies.

### 4. Operations & Continuity
*   **Secure Configuration Baseline (Excel):** Hardening standards and secure configurations for IT assets.
*   **Disaster Recovery & Business Continuity Plan (DRP/BCP):** Strategies for maintaining critical operations (Riyadh HQ & Jeddah DR) during disruptions.

### 5. Performance Evaluation & Auditing
*   **ISMS Performance Report:** Measurement of security KPIs and control effectiveness.
*   **Internal Audit Report:** Independent review findings, nonconformities (NCRs), and observations for continuous improvement.
